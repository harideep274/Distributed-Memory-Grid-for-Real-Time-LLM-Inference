01 — THE IDEA

Inference without
the single-box ceiling.

A learning project investigating the control plane and tensor layouts behind multi-node inference. The current demo uses synthetic tensors so the correctness story stays easy to inspect.

01 / SHARD
↗

Split the weights

Column and row partition helpers split dense tensors into explicit, contiguous shards and reconstruct them with metadata checks.
